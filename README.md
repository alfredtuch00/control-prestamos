# Control de Préstamos

App web de una sola página (HTML + CSS + JS, sin dependencias) para llevar el control mes a mes de préstamos personales: cuotas por mes, estados (Pagado / Por vencer / Vencido), resumen mensual, tablas de amortización, alta y edición de préstamos, exportación CSV y respaldo JSON.

**Este repositorio no contiene datos.** Los datos viven en un repositorio privado aparte y la app los lee/guarda con la API de GitHub usando un token que el usuario pega una vez en cada dispositivo (se guarda solo en ese navegador).

Configuración: constantes `GH_OWNER`, `GH_REPO`, `GH_PATH` y `GH_BRANCH` al inicio del script en `index.html`.

Sitio: https://alfredtuch00.github.io/control-prestamos/
